# 🎮 GameVault

A simple **Game Library Manager** built using AngularJS 1.8.2, HTML and CSS.

## ✨ Features

- ➕ Add games
- 📋 View games
- ✏️ Edit game details
- 🗑️ Delete games
- 🎭 Genre management
- 🎯 Status management
- ⭐ Game ratings
- 💾 Data persistence using localStorage
- 📱 Responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- AngularJS 1.8.2

## 🚀 How to Run

### Download ZIP

1. Click the **Code** button on GitHub.
2. Select **Download ZIP**.
3. Extract the ZIP file.
4. Open the project folder.
5. Open `index.html` in your browser.

No installation or backend setup is required.
